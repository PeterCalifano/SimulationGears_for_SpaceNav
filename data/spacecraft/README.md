# Spacecraft geometry

`farinella_cubesat_6U.obj` is the DART-team Farinella CubeSat mesh copied
without modification from
`nav-backend/data/shape-models/farinella_cubesat_6U.obj` on 19 September 2026.
The OBJ vertex coordinates are in metres. Its SHA-256 is
`fae398105448a2376a4c7cc46b8fa3f520a676b34b77e763d30b52acb4f4a69d`.
COSMICA uses this geometry only to build simulator-truth SRP panels; the
onboard filter retains its separately configured cannonball model.
